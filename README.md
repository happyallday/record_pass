# 密码管理器

一个安全可靠的Windows桌面密码管理应用程序，使用WPF和.NET 8开发。

## 功能特性

### 🔒 安全性
- **AES-256加密**：所有密码使用AES-256算法加密存储
- **DPAPI保护**：主密码相关密钥使用Windows DPAPI保护
- **本地存储**：所有数据存储在本地，不依赖云服务
- **密码强度检测**：自动检测密码强度并提供建议
- **剪贴板自动清空**：复制密码后30秒自动清空剪贴板

### 🔐 密码管理
- **添加/编辑/删除**密码条目
- **密码生成器**：可定制复杂度的密码生成
- **密码显示/隐藏**：方便查看和管理密码
- **一键复制**：快速复制用户名和密码
- **搜索功能**：快速查找密码条目

### ⏰ 提醒系统
- **自定义提醒周期**：为每个密码设置不同的提醒周期
- **智能提醒**：自动检测需要修改的密码
- **提醒状态显示**：直观显示密码到期状态
- **提醒导出**：导出提醒报告

### 💾 数据管理
- **数据备份**：导出完整的数据库备份
- **数据恢复**：从备份文件恢复数据
- **SQLite数据库**：轻量级、高效的本地数据库

## 系统要求

- **操作系统**：Windows 10/11
- **.NET运行时**：.NET 8.0 或更高版本
- **磁盘空间**：约50MB（包括运行时）

## 安装和使用

### 1. 安装.NET运行时
如果没有安装.NET 8.0，请从以下地址下载安装：
https://dotnet.microsoft.com/download/dotnet/8.0

### 2. 编译程序
在项目根目录运行：
```bash
dotnet build
```

### 3. 运行程序
```bash
dotnet run --project PasswordManager/PasswordManager.csproj
```

### 4. 首次使用
1. 运行程序后会显示登录界面
2. 设置一个强主密码（至少8位，建议包含大小写字母、数字和特殊字符）
3. 主密码将用于加密所有密码数据，请务必牢记
4. 如果忘记主密码，将无法恢复任何数据

## 使用说明

### 添加新密码
1. 点击"添加密码"按钮
2. 填写网站名称、用户名、密码等信息
3. 使用密码生成器创建强密码
4. 设置提醒周期（建议30-90天）
5. 点击"保存"

### 管理密码
- **查看详情**：双击密码条目查看详细信息
- **编辑密码**：选中密码条目后点击"编辑"
- **删除密码**：选中密码条目后点击"删除"
- **搜索密码**：在搜索框中输入关键词进行搜索

### 密码生成器
- 密码长度：8-32位
- 可选字符类型：大写字母、小写字母、数字、特殊字符
- 避免歧义字符（如0和O，1和l）

### 提醒系统
- 程序启动后自动开始监控密码到期情况
- 每30分钟检查一次需要提醒的密码
- 通过系统托盘或弹窗显示提醒
- 查看提醒：点击菜单"提醒" -> "查看需要修改的密码"

### 数据备份
1. 点击"密码" -> "导出密码备份"
2. 选择保存位置和文件名
3. 备份文件将包含完整的数据库

### 数据恢复
1. 点击"密码" -> "导入密码备份"
2. 选择之前导出的备份文件
3. **警告**：此操作将覆盖现有数据

## 安全建议

1. **主密码安全**：
   - 使用强密码（至少12位，混合大小写字母、数字、特殊字符）
   - 不要与其他网站使用相同的密码
   - 定期更换主密码（建议每年更换）

2. **系统安全**：
   - 保持操作系统和.NET运行时最新
   - 设置Windows登录密码
   - 启用Windows加密功能

3. **密码策略**：
   - 为不同网站使用不同密码
   - 定期更换重要账户密码
   - 避免使用个人信息作为密码

4. **数据备份**：
   - 定期备份密码数据库
   - 将备份文件保存在安全位置
   - 可以加密备份文件

## 数据存储位置

数据默认存储在以下目录：
```
%LocalAppData%\PasswordManager\
```

包括：
- `passwords.db` - 密码数据库
- `master.key` - 主密钥文件（DPAPI加密）

## 故障排除

### 无法启动程序
1. 检查.NET 8.0是否正确安装
2. 检查是否有足够的权限访问AppData目录
3. 查看Windows事件查看器中的错误信息

### 编译问题
如果遇到编译错误，请确保：
1. 使用.NET 8.0 SDK或更新版本
2. 运行 `dotnet restore` 恢复NuGet包
3. 确保所有依赖包已正确安装

### 密码解密失败
1. 确认主密码是否正确
2. 检查数据文件是否被修改或损坏
3. 尝试从备份恢复数据

### 提醒功能不工作
1. 确认程序正在运行
2. 检查Windows通知设置
3. 重新启动程序

## 开发信息

### 技术栈
- **框架**：.NET 8.0 WPF
- **数据库**：SQLite (Microsoft.Data.Sqlite)
- **加密**：AES-256 + Windows DPAPI
- **UI**：XAML

### 项目结构
```
PasswordManager/
├── Models/           # 数据模型
├── Services/         # 业务服务（加密、数据库、提醒）
├── Utils/            # 工具类（密码生成器）
├── Views/            # 窗口和UI
├── ViewModels/       # 视图模型（MVVM架构）
└── App.xaml          # 应用程序入口
```
